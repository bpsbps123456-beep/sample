# 한국어·브라질 포르투갈어

화면 모서리의 언어 메뉴에서 `한국어`와 `Português (Brasil)`을 전환한다. 선택은 `mungcamp.language`에 저장한다. 저장소가 차단된 브라우저에서도 현재 화면의 전환은 동작한다. 질문·답변·채팅 입력을 유지하기 위해 언어 변경 시 페이지를 새로 열지 않는다.

`js/locale-pt-BR.js`는 UI 사전, `js/i18n.js`는 번역·언어 선택·동적 DOM 갱신을 담당한다. `util.js` 다음에 사전과 번역 모듈을 먼저 로드한다. 장면 캔버스의 UI 글자는 `MC.I18n.t`를 통해 그린다. 공유 상태·식별자·저장 데이터는 원래 값을 유지한다.

사전의 `{n}` 등 숫자 자리와 `{state}` 등의 UI 상태 자리를 지원한다. 참가자 이름·질문·보기·답변·채팅·건의·직접 적은 팻말은 자동 번역하지 않는다. 새 사용자 콘텐츠 영역은 `translate="no"`로 표시한다. 작은 책장의 한국어 소설 원문도 유지하며 포르투갈어 안내에서 원문 언어를 알린다.

코드나 사전을 수정하면 `sw.js` 캐시 버전과 HTML의 언어 자산 버전도 갱신한다. `npm test`와 실제 브라우저에서 언어 왕복 전환·저장·사용자 입력 보존을 확인한다.
