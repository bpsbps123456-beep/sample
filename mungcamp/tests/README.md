# 멍캠프 시험

사이트를 고친 뒤 실제 브라우저(Playwright의 Chromium)로 열어, 멍이가 걷고 앉고 눕고 함께 보이는지 확인합니다.
서버도 스스로 띄웁니다(정적 서버, 또는 `server/presence.js`). 빈 포트를 골라 쓰므로 따로 준비할 것이 없습니다.

## 돌리기

```bash
cd mungcamp
npm test                      # 모두 (5~6분)
node tests/run.js sea forest  # 이름에 sea, forest 가 들어간 것만
node tests/sea.test.js        # 하나만
```

- Node 18 이상이 필요합니다.
- Playwright: Claude Code 웹 세션에는 이미 깔려 있습니다. 내 컴퓨터에서는 한 번만
  `npm i -D playwright && npx playwright install chromium`
- 화면 사진은 `tests/shots/`에 남습니다(저장소에는 올리지 않습니다).
- 결과는 줄마다 `✓`(통과) 또는 `✗`(실패)로 나오고, 실패가 하나라도 있으면 끝 코드가 1입니다.
- 기존 시험의 `person()`은 실제 사람 간 동작을 격리하기 위해 상주 멍이를 끕니다. `person({ residents: true })`로 실제 서비스처럼 켜며, `residents.test.js`에서 인원수·일정·지형·자리 유지·실제 접속자 우선을 확인합니다.

## 시험 쓰기

`lib.js`의 도구를 씁니다: `enter(page, 주소, 장소)`(장소에는 걸어서만 가므로 마을에서 그 앞에 서서 들어간다), `staticServer()`, `presenceServer(env)`, `person({ nick, look, phone })`(사람 한 명 = 브라우저 하나, `tab()`으로 같은 브라우저의 새 탭), `until(page, 조건)`, `tapVisitor(page)`, `check(맞는지, 이름)`, `shot(page, 이름)`.
