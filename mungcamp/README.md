# 멍캠프 (MUNG CAMP)

잠깐 멍 때리고 가는 웹 힐링 캠프입니다. 세 자리 중 하나를 골라 앉습니다.

| 자리 | 장면 | 할 수 있는 것 |
| --- | --- | --- |
| 불멍 · 모닥불 글램핑 | 별 아래 벨텐트, 줄전구, 모닥불 | 장작 넣기, 걱정을 장작에 적어 직접 끌어 불에 넣기, 불 톡 건드리기 |
| 물멍 · 달빛 바다 | 블루아워 바다, 달빛 윤슬, 등대 | 10초 주기 파도에 맞춘 호흡, 물 건드려 동심원 만들기 |
| 숲멍 · 편백 숲의 아침 | 빛내림, 빛 속 먼지, 고사리 | 화면을 눌러 바람 일으키기, 계곡물과 새소리 |

모든 장면에서 쓸 수 있는 기능:

- 호흡 안내: 공명 호흡, 주기적 한숨, 박스 호흡
- 타이머: 5, 10, 20(기본), 30분, 제한 없음
- 소리: 층별 볼륨 조절
- 화면만 보기: 가만히 두면 조작부가 사라짐
- 기기 안 화면 유지(Wake Lock)
- 전체 화면
- 마음 날씨 체크인/체크아웃과 쉼 기록: 이 기기에만 저장
- 위기 상담 번호 안내: 109, 1577-0199, 1588-9191

## 연구 → 기능

| 연구 | 사이트에 반영한 부분 |
| --- | --- |
| Kaplan (1995) 주의 회복 이론, Berman 외 (2008) | '부드러운 매혹'이 있는 장면. 알림·점수·광고 없이, 6초 동안 조작이 없으면 조작부가 사라짐 |
| Taylor (2006) 프랙탈 | 불꽃·파도·바람의 움직임을 1/f 요동(`MC.fbm`)으로 생성 |
| Killingsworth & Gilbert (2010), Baird 외 (2012) | 걱정으로 빠지지 않게 시선을 둘 대상을 화면 가운데에 두고, 시작할 때 "다시 불꽃으로" 안내 |
| Lynn (2014) 모닥불과 혈압 | 불멍은 소리와 함께 시작. 장작을 넣어 오래 머물 수 있게 함 |
| Wiessner (2014) 불가의 대화 | 밤 불가의 분위기(텐트, 줄전구, 풀벌레) |
| Briñol 외 (2013) 생각을 버리는 행동 | 걱정을 장작에 적어 **직접 끌어서** 불에 넣음. 연구에서 상상만으로는 효과가 없었기 때문. 입력은 저장·전송하지 않음 |
| White 외 (2010) 블루 스페이스 | 물멍 장면 |
| Buxton 외 (2021), Alvarsson 외 (2010) 자연의 소리 | 파도·계곡물·새소리·장작 소리를 실시간 합성 |
| Park 외 (2010) 산림욕 | 편백 숲 장면 |
| Lehrer & Gevirtz (2014) 공명 호흡 | 5초 들숨·5초 날숨. 물멍 파도 주기를 정확히 10초(`MC.WAVE_T`)로 맞추고, 호흡 안내를 파도 위상에 동기화 |
| Balban 외 (2023) 주기적 한숨 | 호흡 안내에 주기적 한숨·박스 호흡 |
| Hunter 외 (2019) 자연 처방 20~30분 | 타이머 기본값 20분 |
| Kjellgren & Buhrkall (2010), Browning 외 (2020) | 화면 속 자연의 한계를 밝히고, 세션 끝에 실제 바깥으로 나가 보길 권함 |

연구 내용은 사이트에 글로 싣지 않고, 장면·소리·호흡·타이머 설계에만 반영했습니다. 위 표는 그 설계 근거를 남겨 두는 기록입니다.

## 대규모 접속을 위한 구조

멍캠프는 **서버가 필요 없는 정적 사이트**입니다.

- 그림은 Canvas 2D, 소리는 Web Audio로 **접속한 기기에서 실시간 생성**합니다. 영상·음원 파일이 하나도 없습니다.
- 페이지 전체(HTML+CSS+JS)가 gzip 기준 약 50KB입니다. 폰트는 Google Fonts CDN에서 받습니다.
- 서버가 하는 일은 정적 파일을 건네주는 것뿐이라, CDN(Cloudflare Pages, Netlify, Vercel, GitHub Pages)에 올리면 동시 접속자가 늘어도 서버 부하가 거의 늘지 않습니다.
- 서비스 워커가 파일을 캐시하므로, 다시 방문할 때는 네트워크를 거의 쓰지 않고 오프라인에서도 열립니다.
- 느린 기기에서는 프레임 시간을 보고 입자 수를 자동으로 줄입니다(`MC.Runner`). 화면 픽셀 수에도 상한을 둡니다.
- 탭이 가려지면 그리기를 멈춥니다. 소리는 1초 넘게 미리 예약해 두어 백그라운드에서도 끊기지 않습니다.

### 배포

빌드 과정이 없습니다. `mungcamp/` 폴더를 그대로 올리면 됩니다.

- **Cloudflare Pages / Netlify**: 배포 폴더를 `mungcamp`로 지정합니다. 캐시 헤더는 `_headers`에 있습니다.
- **Vercel**: Root Directory를 `mungcamp`로 지정합니다. 헤더는 `vercel.json`에 있습니다.
- **GitHub Pages**: `mungcamp` 폴더를 Pages 소스로 지정합니다.

JS·CSS를 바꿔 배포할 때는 `sw.js`의 `CACHE` 이름 숫자를 올려 주세요. 그래야 재방문자도 새 버전을 받습니다.

### 로컬에서 보기

`index.html`을 브라우저로 바로 열어도 동작합니다. 서비스 워커까지 확인하려면 로컬 서버를 띄웁니다.

```bash
cd mungcamp
python3 -m http.server 8000
# http://localhost:8000
```

## 파일 구성

```
mungcamp/
├── index.html          첫 화면, 연구 섹션, 세션 화면 마크업
├── css/style.css       디자인 토큰과 모든 스타일
├── js/util.js          난수·1/f 요동·저장소·장면 실행기(MC.Runner)
├── js/audio.js         Web Audio 합성: 장작, 풀벌레, 파도, 계곡물, 새, 종소리
├── js/scene-fire.js    불멍 장면 (불꽃 입자, 장작, 걱정 장작, 텐트, 줄전구)
├── js/scene-water.js   물멍 장면 (물결, 윤슬, 물가, 등대, 동심원)
├── js/scene-forest.js  숲멍 장면 (편백, 빛내림, 먼지, 낙엽, 고사리)
├── js/breath.js        호흡 안내
├── js/app.js           화면 흐름, 타이머, 기록, 단축키
├── sw.js               오프라인 캐시
└── manifest.webmanifest, icon*.png, icon.svg
```

## 다음에 해 볼 만한 것

- **함께 불멍**: "지금 N명이 이 불 앞에 있어요" 같은 실시간 접속자 표시. 불가에서 함께 있다는 느낌(Wiessner, 2014)을 살릴 수 있습니다. 정적 구조를 유지하려면 Cloudflare Durable Objects나 Supabase Realtime Presence처럼 접속 수만 세는 가벼운 서비스를 붙이고, 숫자는 몇 초 간격으로만 갱신하는 편이 대규모에 안전합니다.
- 비 오는 날 텐트, 눈 내리는 숲 같은 날씨·계절 변주.
- 수면용 긴 타이머와 점점 작아지는 소리.

## 안내

멍캠프는 잠깐 쉬어 가는 곳이고, 진료나 상담을 대신하지 않습니다.
